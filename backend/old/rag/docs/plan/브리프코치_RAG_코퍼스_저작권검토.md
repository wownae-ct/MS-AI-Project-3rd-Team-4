# 브리프코치 — RAG 코퍼스 저작권 검토

> 작성일: 2026-08-19 | 실제 후보 소스를 검색해 라이선스/이용조건을 확인하고, 카테고리별로 사용 가능 여부를 판정했습니다.

## 결론 먼저 (두괄식으로)

당초 계획했던 "채용 플랫폼·개인 블로그 아티클 30~50건"은 **대부분 원문 저장이 불가능**합니다(전부 "All rights reserved" 기본 원칙, 명시적 오픈라이선스 없음). 대신:

1. **국가기관 발행 자료(공공누리 대상)를 우선 소스로 채택** — 존재를 확인했고, 두괄식/문서작성 카테고리는 이걸로 대체 가능
2. **상업/개인 콘텐츠는 "원문 저장 금지, 개념만 참고해 팀이 새로 쓰기"** 로 전환
3. 이렇게 하면 **저작권 리스크 없이** 오늘 바로 코퍼스 작성을 시작할 수 있습니다 — 별첨 `브리프코치_RAG_코퍼스_v1_starter.md`에 원본 문구를 전혀 쓰지 않고 새로 쓴 초안 12건을 만들어뒀습니다.

| 후보 소스 | 성격 | 라이선스 확인 결과 | 판정 |

### ④ 자체 작성 체크리스트

문제 없음 — 팀이 처음부터 직접 쓰는 콘텐츠라 저작권 이슈 자체가 없습니다. 오히려 **①③ 카테고리의 부족분을 여기서 채우는 것**이 가장 안전한 전략입니다.

## 수정된 코퍼스 구성 계획

| 구분 | 기존 계획 | 수정안 |
|---|---|---|
| STAR 기법 | 채용플랫폼 원문 10~15건 | NCS 의사소통능력 모듈 기반 재정리 3~5건 + 팀 자체 작성 7~10건 |
| 두괄식/비즈니스 라이팅 | 블로그 원문 10~15건 | **국립국어원 자료 기반** 재정리 5~8건 + 팀 자체 작성 5~7건 |
| 기술 커뮤니케이션 | 블로그 원문 10~15건 | 전량 팀 자체 작성 10~15건 (블로그는 아이디어 참고용으로만 열람) |
| 자체 체크리스트 | 5~10건 | 5~10건 (변경 없음) |

> 총량은 원래 목표(30~50건)와 비슷하게 유지되지만, **출처가 명확한 공공자료 + 팀이 직접 쓴 원본 콘텐츠**로 구성이 바뀌어서 오히려 근거검증 에이전트가 "이 근거가 진짜 있는 내용인가"를 확인하기 쉬워집니다(팀이 원저작자이므로 원문 대조가 항상 가능).

## 다음 확인 필요 사항

- 국립국어원 두 자료의 정확한 공공누리 유형(1~4유형 중 무엇인지) — 다운로드 페이지에서 재확인 후 인용 시 출처 표기 형식을 그 유형에 맞게 작성.
- NCS 학습모듈에서 텍스트만 발췌하고 도표/이미지는 제외하는 작업 필요.
