# features/rules — T1 룰 엔진 (§4.5)

각도 기반 폼 판정·렙 카운트의 클라이언트 측 **잠정 판정**. **M4에서 구현** (룰 회귀 픽스처는 G-3 확정 후).

- T1 판정은 잠정 결과다 — 서버 판정(`verdict_source: rules/tcn/hybrid`) 도착 시 **서버 권위로 정정**한다 (§4.5·§2.1).
- 판정 임계값을 하드코딩하지 않는다(P0) — 세션 시작 시 REST로 `rule_params` 수신·캐시, 실패는 3단 강등
  (번들 기본 → IndexedDB 캐시 → "코칭 비활성" 배너). **조용한 비활성화 금지** (§4.5.1).
- 엔진은 순수 함수로 유지(입력: CANON19 월드 채널) — 지연 목표는 「T1 판정 SLO」(§4.5, Worker 추론 SLO와 비교 금지).
- 오디오 큐(`cue-scheduler`)는 디바운스 「모델·오디오」 규격 · 우선순위 안전 > 폼 > 격려 (§4.5.2).
