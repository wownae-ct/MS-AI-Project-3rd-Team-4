# shared/ui — 공용 UI

화면 컴포넌트 공용 조각 (배너·버튼·진행률 등). 화면 조립은 `pages/`가 담당한다 (§6.1).

**M4 디자인 파운데이션 방침** (컴포넌트 구현 시 준수):

- 디자인 토큰은 CSS 변수로 선언하고 컴포넌트는 토큰만 참조한다 (색·간격·타이포 하드코딩 금지).
- 아이콘은 인라인 SVG(또는 스프라이트) — 외부 아이콘 CDN 금지 (§6.2 self-hosting 원칙 준용).
- 이미지·영상 자산: 카메라 프리뷰는 `<video>` 요소 + 오버레이 캔버스(§4.2)이며, **원본 영상 프레임은 어떤 경우에도
  네트워크로 전송하지 않는다** (§6.6, P0). 정적 이미지는 번들 동봉(빌드 해시 캐시).
- 오디오 큐에는 자막(시각 표시)을 병행한다 (§4.5.2 접근성).
- 필수 공용 컴포넌트(전부 M4): Wake Lock 실패 배너(§5.3) · "코칭 기본값/비활성" 배너(§4.5.1) ·
  수동 재연결 버튼(「백오프」) · 진행률 UI(「모델·오디오」).
