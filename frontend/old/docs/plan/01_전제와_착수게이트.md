# 01. 적용 전제와 착수 게이트 (Definition of Ready)

> **유형** 기준 · **문서 상태** 🟢 활성 · **최종 갱신** 2026-08-18 · **종결 조건** G-1~G-4 전건 해소 + 확정 전제 3건 무변동 확인 (M5 착수 시 재판정)

설계서 v2.1 부록 D.1의 착수 게이트 4건(G-1~G-4)과 사전 준비물의 **2026-08-17 기준 판정**.
게이트의 규범 출처는 설계서 v2.1 부록 D — 이 문서는 실행 추적용이다.

## 확정 전제 3건 (설계서 §0 — 뒤집으려면 설계서 개정 절차 경유)

1. **지원 대상은 Chromium(Blink) 계열 한정** — Chrome·Edge·삼성인터넷·웨일, 하한 Chromium 111. iOS 전체·Safari·Firefox는 스코프컷(§6.2.1 안내 화면). 하한 변경은 분기별 StatCounter 실측만.
2. **한국 사용자 기반** — 브라우저 하한·인앱 브라우저(카카오톡) 대응 판단의 근거.
3. **호스팅은 Azure SWA 유지** — WebSocket은 SWA를 경유하지 않고 백엔드 인그레스 직결.

이 전제를 뒤집는 제안(Safari 대응·호스팅 전환 등)은 구현하지 않고 설계서 개정 절차(부록 C.2)를 안내한다.

## 게이트와 무관하게 지금 실행 가능한 것

1. **M1 전체** — FSD 이관 + `shared/protocol` 코덱 + 골든 벡터. 게이트 의존 없음 (단 툴체인·이관은 승인 필요).
2. **M2 준비** — MockWebSocket·시나리오 설계는 게이트 무관. 단 **M2 구현 착수는 G-4 합의 선행**.
3. **외부 요청 발신 3건 (최우선)** — ① G-3 대조 요청(ml 담당) ② G-4 카탈로그 합의 요청(백엔드) ③ 툴체인 정비 승인. 셋 다 **대기 시간이 크리티컬 패스에 걸리는 외부 의존**이다.
