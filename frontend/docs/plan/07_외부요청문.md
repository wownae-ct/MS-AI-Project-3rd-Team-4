## R-A. [ml] TCN 키포인트 정의 ↔ CANON19 대조 요청 (게이트 G-3)

> **요청**: TCN 학습 데이터(AI Hub 라벨)의 키포인트 정의가 아래 CANON19 매핑(설계서 v2.1 §4.4.1)과 일치하는지 대조 확인 부탁드립니다.
> **왜 지금**: 프론트 M3(Worker 파이프라인) 착수 전 확정이 필수인 차단 게이트라, 응답 대기 시간이 일정에 직결됩니다.
> **불일치 시**: 학습 셋 기준으로 프론트 매핑표를 교체합니다(프론트 수정 반경은 `shared/protocol/canon19.ts` 1파일). 회귀 픽스처도 확정 후에 제작합니다.
>
> CANON19: MediaPipe Pose 33랜드마크를 19관절 × 6채널로 축약 — idx 0 nose(←0) · 1 neck(합성 (11+12)/2) · 2/3 shoulder L/R(11/12) · 4/5 elbow(13/14) · 6/7 wrist(15/16) · 8 mid_hip(합성 (23+24)/2) · 9/10 hip(23/24) · 11/12 knee(25/26) · 13/14 ankle(27/28) · 15/16 heel(29/30) · 17/18 foot_index(31/32). 얼굴 세부·손끝 폐기, 합성 관절 visibility는 구성 관절의 최솟값.
> 채널·좌표계 등 상세는 설계서 v2.1 §4.4.1~4.4.2 (팀 문서 채널) 참조.

## R-B. [백엔드] WS 메시지 카탈로그 확정 합의 (게이트 G-4)

> **요청**: WS 메시지 카탈로그를 설계서 v2.1 §3.1 `EnvelopeType` 14종(auth·auth_ok·auth_err·reauth·ping·pong·resume·resume_ok·snapshot·delta·session_pause·session_resume·verdict·error) + §3.2 바이너리 프레임으로 **확정 확인** 부탁드립니다. 규범 문서가 이미 이렇게 확정되어 있어, 이 합의는 계약 변경이 아니라 규범 확인·문서화입니다.
> **배경**: 저장소 일부(초기 뼈대·README)에 구계약(wave0: `session.hello`·`pose.chunk`, 10Hz)이 남아 있었고(프론트 측 잔재는 오늘 정리 완료), 규범(§4.4: 30fps 추론·초당 2윈도우 업링크)과 **데이터율이 약 7배** 달라 서버 수용량 산정에 직결됩니다 — 산정 근거는 설계서 §4.4.4.
> **함께 확정 필요**: ① WS URL 방식 — 현행 `/ws/v1/sessions/{id}` 경로 파라미터 ↔ §2.1.1 "session_id는 인증된 연결 컨텍스트에서 서버 주입" (I-6) ② 티켓 발급 REST 엔드포인트 확정 시점(M2 말 목표) ③ `movement_fault_code.rule_params` 스키마 확정 시점(M4 전).
> **왜 지금**: 프론트 M2(WS 상태 기계) 착수 전 확정 필수 게이트입니다.

## R-C. [CI·인프라] frontend-ci.yml 정비 요청 (I-2)

> **요청**: `frontend-ci.yml` 3건 정비 부탁드립니다 (프론트 소유 영역이 아니라 요청으로 전달).
> ① **Node 20 → 22.12+ 또는 24 LTS** — Node 20은 2026-04-30 EOL 경과 (설계서 §1).
> ② **배포 토큰 → OIDC(`github_id_token`) 전환** — §6.4.2 정규 경로. 전제: SWA 리소스의 Deployment authorization policy를 "GitHub"으로 변경해야 동작. 전환 전이라면 최소한 토큰을 environment 시크릿으로 격리.
> ③ **`npx depcruise src` 단계 추가** (lint 다음) — FSD 경계 CI 게이트(§6.1.1). 설정 파일(`frontend/.dependency-cruiser.cjs`)과 `npm run depcruise` 스크립트는 오늘 저장소에 반영 완료라, 단계 추가만 하면 됩니다.
> 참고: 빌드 명령은 `npm run build`가 이미 `tsc -b`로 갱신되어 **CI 파일 수정 불요**(C-4 자동 해소).
