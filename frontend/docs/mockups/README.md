# mockups — 화면 스펙

> **최종 갱신** 2026-08-21 · **문서 소유** 프론트 담당

## 무엇인가

화면 6개(S1~S6)의 시각 초안이다. 브라우저에서 파일을 직접 열면 된다.

| 파일 | 화면 |
|---|---|
| `s1-onboarding.html` | S1 온보딩 (6단계) |
| `s2-dashboard.html` | S2 대시보드 |
| `s3-category-detail.html` | S3 카테고리 상세 (체크리스트 / 비용 / AI상담 3탭) |
| `s4-timeline.html` | S4 타임라인 |
| `s5-report.html` | S5 리포트 |
| `s6-budget-scenario.html` | S6 예산 재배분 |

## ⚠️ 이 파일들은 구버전이다

같은 디자인 프로젝트에 **인터랙티브 프로토타입**이 따로 있고, 그쪽이 더 최신이다. **여기에만 없는 것:**

- **하단 탭바 4개** (홈 · 타임라인 · 예산 · 리포트)
- **데스크톱 레이아웃** (1160px · 좌측 사이드바 232px + 상단바 + `auto-fit` 그리드)
- **호버 상태 27건**

이 정적 사본은 **화면 단위 시각 참조**로만 쓴다. 앱 셸·내비게이션·데스크톱은 [../design/layout.md](../design/layout.md)에 계약으로 옮겨 두었으므로 그쪽을 본다.

## 가공 내역

원본은 파일당 약 1.78 MB였다 — Wanted Sans woff2 두 벌이 base64로 임베드돼 있었다.

- **임베드 폰트를 걷어내고** 동일 버전(v1.0.3) CDN `@import`로 교체했다. 디자인 충실도를 잃지 않으면서 6개 합계 **10.67 MB → 77.7 KB (99.27% 감소)**
- 그 외 **마크업과 스타일은 한 글자도 바꾸지 않았다**
- 각 파일 첫 줄 주석에 같은 내용이 있다

폰트 체인은 실측 확인했다 — CSS 200(579 B) → 상대경로 woff2 200(1,289,292 B) · `access-control-allow-origin: *` (file:// 에서도 로드된다) · `font-weight: 400 1000`(원본이 쓰던 400·700을 모두 커버).

## 이 목업에서 받는 것과 받지 않는 것

**원칙: 값은 받지 않고 구조는 받는다.**

| | 지위 |
|---|---|
| **화면 목록 · 정보구조 · 데이터 요구 · 화면 간 관계** | **사실상 스펙** — 다른 출처가 없다 |
| **색 · 서체 · 형태 · 그림자** | **제안서** — 채택은 [../design/decisions.md](../design/decisions.md) 개정을 거친다 |

목업의 토큰 블록은 현재 `theme.css`와 **7색 · 라운드 3종 · 서체 스택이 일치한다** — 같은 디자인 확정 과정에서 나왔기 때문이다. 단 **8번째 토큰 `--page-canvas: #EDEAE6`** 이 `:root`에 있고 `html, body` 배경으로 실제 쓰인다(6파일 전부). 이건 팔레트 밖 색이다 — 아래 표에 포함.

### 규범을 넘어선 것 — 두 출처를 구분해 적는다

> ⚠️ **이 표의 수치는 출처가 둘이다.** 「정적 사본」은 이 폴더의 6개 HTML에서 **이 브랜치 안에서 재현 가능**한 실측이다(명령은 아래). 「프로토타입」은 저장소 밖 인터랙티브 판본에서만 관측됐고 **이 브랜치에서 재현할 수 없다** — [../design/README.md](../design/README.md) 「자립 원칙」에 따라 등급을 낮춰 표기한다. 규범 결정의 **정량 근거로는 정적 사본 수치만 쓴다.**

| 항목 | 정적 사본 실측 (재현 가능) | 프로토타입에서만 관측 (재현 불가 · 참고) | 판정 |
|---|---|---|---|
| **토큰 밖 라운드** | `50%`×13(원형 썸·아바타) · `40px`×6 · `32px`×6 · `16px`×5 · `12px`×2 · `14px`×4(복합 포함) · `5px` `4px` `2px` 각 1 | 16px×13 · 12px×11 · 6px×4 · 9px · 18px | 4단계로 정규화 — D1 |
| **primary 면 채움** | S5 카드 전면(화면의 약 1/4) | — | 면적으로 등급 분리 — D2. **기각 확정**(2026-08-22): `surface` 카드 + `primary` 제목 + `line` 보더 행 |
| **파스텔 그라디언트** | **0건** — S3 벤치마크 막대는 이미 `ink-soft` + `opacity:.35` 단색으로 그려져 있다 | `linear-gradient(90deg,#F1DEE7,#D9AFC4)` 1건 | 기각 — D3 |
| **팔레트 밖 색** | **`#EDEAE6`(`--page-canvas`) 1색** — 6파일 전부, 캔버스 배경 | `#77354F`(9) `#6E3150` `#D9AFC4` `#C9C3BC` `#A39C96` `#E4CBD8` `#FBFAF9` `#FBF6F8` + `opacity:.55` 옅은 플럼 | 프로토타입 색은 2건만 검토(D4 · D5), 나머지 기각. `#EDEAE6` 는 **미판정 — 아래** |
| **`box-shadow`** | **1건** — S6 슬라이더 썸 `0 0 0 1px var(--color-primary)` (흐림·오프셋 0 = **링**) | 썸 `0 1px 4px rgba(29,27,25,.25)` 3건 | 기각 — 전자는 D9(`ring`→`outline`), 후자는 Flat-By-Default |

**`#EDEAE6` 판정은 미결이다.** 목업은 앱 프레임(390pt) 바깥 캔버스를 이 색으로 칠한다. 앱 안에서는 쓰이지 않으므로 토큰 추가 대상이 아닐 가능성이 높지만, 데스크톱 레이아웃(1160px)에서 사이드바 밖 여백을 어떻게 칠할지는 [../design/layout.md](../design/layout.md)가 정한다 — 그때 판정한다.

재현 명령(이 폴더에서):
```bash
grep -ohE 'border-radius\s*:\s*[^;}]+' s*.html | sed -E 's/border-radius\s*:\s*//' | sort | uniq -c | sort -rn
grep -ohE '#[0-9a-fA-F]{3,8}\b' s*.html | tr a-f A-F | sort | uniq -c
grep -nE 'box-shadow|linear-gradient' s*.html
```

상세는 [../design/decisions.md](../design/decisions.md).

## 목업이 답하지 않는 것

**시각 스펙이지 상호작용·접근성 스펙이 아니다.**

| 항목 | 상태 |
|---|---|
| `aria-*` · `role=` | **0건** — 스위치 · 칩 · 체크박스 · 토글이 전부 `<span>`이다 |
| 로딩 · 빈 · 오류 상태 | **6화면 전부 0건.** AI 상담 스트리밍 중 화면도 없다 |
| 폼 검증 · 오류 메시지 | 없음 (S1 총예산 · 하객 수) |
| S6 재분배 규칙 | 한 카테고리를 올리면 **어디서 빼는지** 없음 |
| 브레이크포인트 | 1160px 하나뿐, 그 사이 구간 없음 |

접근성은 Base UI가 담당하고 규범은 [../design/a11y.md](../design/a11y.md)를 따른다.

## 목업의 타이포·터치타겟을 그대로 쓰지 않는다

| 항목 | 목업 | 이 저장소 |
|---|---|---|
| 주 본문 | 13~14px | **16px** |
| 캡션 | 9.6~11.8px (`.6rem`~`.74rem`) — **12px 미만 50건 / 전체 `font-size` 선언 111건** (정적 사본 실측) | 12px |
| 입력 필드 | 13px×6 · 14px×4 | **16px 미만 금지** |
| 터치 타겟 | 16~38px | **44px** |

목업의 밀도는 390pt 프레임을 데스크톱 캔버스에 1:1로 그린 데서 온 것이라 실기기 판독성 검증을 거치지 않았다. **한 단계 올려 적용한다.** 근거는 [../design/a11y.md](../design/a11y.md).

## 갱신할 때

- 디자인 프로젝트에서 새 판본을 받으면 **같은 가공(폰트 CDN 치환)을 거쳐** 이 폴더에 덮어쓰고, 이 문서의 「구버전이다」 절을 다시 확인한다
- 목업이 바뀌어 규범 판정이 달라지면 [../design/decisions.md](../design/decisions.md)를 먼저 고친다
