## 🧭 시작 전에: 헷갈리기 쉬운 것 — Managed Identity가 2개 있다

아래 내용을 채워나가다 보면 "이 클라이언트 ID가 그 클라이언트 ID인가?" 하고 헷갈리기 쉽다. 이 프로젝트는
**AAD Managed Identity를 2개** 만들어서 용도를 완전히 분리해뒀다. 지금 뭘 채우고 있는지 헷갈릴 때 이 표로
돌아와서 확인하자.

| Identity | 이름(Bicep) | 배포 출력 필드명 | 누가 쓰나 | 뭘 하려고 쓰나 |
|---|---|---|---|---|
| **backend identity** | `<prefix>-backend-id` | `backendIdentityClientId` | backend / rag-cronjob **파드** | Key Vault 시크릿(openai-key, pg-connstr 등) 읽기, Storage 접근, Postgres AAD 인증, OpenAI 호출 |
| **image updater identity** | `<prefix>-image-updater-id` | `imageUpdaterIdentityClientId` | **ArgoCD Image Updater**(클러스터 전체 컴포넌트 1개) | ACR에 새 이미지 태그가 올라왔는지 조회 |

즉 `secretproviderclass.yaml`처럼 **backend/rag-cronjob 파드가 쓰는 파일**에 들어가는 클라이언트 ID는
전부 **backend identity**(`backendIdentityClientId`)다. `imageUpdaterIdentityClientId`는 ArgoCD Image
Updater 설정(`infra/ansible/playbooks/bootstrap-cluster.yml`, `infra/k8s/argocd/README.md`)에만 들어가고,
다른 곳엔 안 쓴다.

```bash

```
