# ingest

원본 문서 → 정제(가공) 단계. 소스별로 폴더 하나씩(`<source>/`), 각각 다음 3개를 둔다:

```
<source>/
  raw_data/   원본 파일(PDF 등, 큐레이션 전) — 대용량이라 추적 안 함
  work/       파싱/정제 중간 산출물 — 추적 안 함
  parse.py    정제 코드(원본 -> ../../rag_corpus/에 정제 결과 저장) — 추적함
```

정제 코드(`parse.py` 등)만 git으로 추적하고 `raw_data/`, `work/`는 `.gitignore`로 뺀다
(2nd팀 프로젝트 `data/ingest/` 패턴 재사용 — "인제스트 코드가 코퍼스를 만드는 유일한 소스"이므로 코드만 있으면 재현 가능).

현재 소스 2개(운동 가이드, 부상/안전 가이드라인) — 제안서 기준 초기값, 더 필요하면 폴더만 추가.
